## Overall visual direction

Create a premium, elegant, warm, and contemporary salon experience. The website should feel luxurious without being excessive, appealing to both men and women.

Use this color palette:
- Deep plum or dark aubergine for the main background
- Warm ivory or soft cream for light sections
- Champagne gold for accents, borders, buttons, and highlights
- Muted blush pink or dusty rose as a secondary accent
- Charcoal for readable body text

Use sophisticated typography:
- Headings: Cormorant Garamond, Playfair Display, or another elegant serif font
- Body text and buttons: DM Sans, Manrope, or another clean modern sans-serif font

The design should have:
- Generous whitespace
- Soft rounded corners
- Thin gold borders
- Subtle gradients
- High-quality salon imagery
- Strong visual hierarchy
- A premium editorial feel
- Excellent readability and accessibility

Do not make the design look like a generic beauty salon template. Make it feel distinctive and branded for “Lavish Unisex Salon.”

## Interactions and animation

Use tasteful, premium animations:
- Fade-up reveal animations on scroll
- Smooth scrolling between sections
- Gentle image zoom on hover
- Button hover transitions
- Subtle card lift effects
- Animated gold accent lines
- Soft hero image movement or parallax, but keep it lightweight
- Mobile menu slide/fade animation
- Appointment form success animation

Animations should feel calm and refined, not flashy. Respect `prefers-reduced-motion` and disable or reduce animations for users who request less motion.

## Technical requirements

- Use a clean, maintainable React implementation with Tailwind CSS or an equally robust styling system.
- Make the site fully responsive for mobile, tablet, and desktop.
- Prioritize mobile usability because many salon customers will visit from their phones.
- Use reusable components for navigation, buttons, service cards, gallery items, reviews, and forms.
- Keep business content in a central editable data/config file wherever practical.
- Use semantic HTML and accessible labels.
- Ensure strong color contrast and keyboard accessibility.
- Add SEO-friendly title, meta description, Open Graph metadata, and structured local-business data where appropriate.
- Optimize images with lazy loading and responsive sizing.
- Avoid unnecessary dependencies.
- Ensure the website runs successfully in Replit without requiring private API keys.
- Add a favicon or simple branded text favicon if no logo is available.
- Include a clear README explaining where to edit the business details, services, images, social links, hours, and contact information.
